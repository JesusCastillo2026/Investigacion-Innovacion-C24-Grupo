# Hardware y modelos de VigiAire

Esta carpeta reúne la representación estructural del producto y el circuito electrónico simulado. Desde la semana 8, el prototipo electrónico se desarrolla en Wokwi; no se presenta como un ensamble electrónico físico funcional.

## Contenido

- [Circuito simulado en Wokwi](./Circuito_Simulado_Wokwi/): firmware ESP32, diagrama de componentes y guía de ejecución. [Abrir simulador](https://wokwi.com/projects/478264195609475073).
- [Modelos 3D de VigiAire](./Modelo_3D_Tinkercad/): enlace al diseño de Tinkercad y modelos STL de referencia para la carcasa y el ensamble conceptual.

El circuito se prueba de forma virtual con ESP32, Gas Sensor de Wokwi (señal de gas/humo tipo MQ-2), LCD 16×2, tres LEDs y resistencias. La señal del sensor no mide PM2.5 ni calidad real del aire. Los archivos STL son diseños de referencia y no acreditan una fabricación física validada.
