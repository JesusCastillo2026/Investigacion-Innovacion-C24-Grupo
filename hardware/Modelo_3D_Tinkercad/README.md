# Modelo 3D de VigiAire en Tinkercad

El modelo de la carcasa y el ensamble conceptual se trabajaron en Tinkercad. Se puede consultar y continuar editando desde este enlace:

- [Abrir modelo VigiAire en Tinkercad](https://www.tinkercad.com/things/dmxYdAp2bKB-copy-of-vigiaire/edit)

El modelo 3D representa la estructura propuesta del dispositivo. El circuito funcional actual se encuentra en [Circuito_Simulado_Wokwi](../Circuito_Simulado_Wokwi/) y se ejecuta virtualmente; no implica que exista un ensamble electrónico físico.

**Archivos 3D exportados:** en el checkout disponible no se encontraron archivos STL u otros formatos descargables del modelo. El enlace de Tinkercad se deja como referencia del diseño en línea. Para guardar una copia editable o imprimirla, exporta desde Tinkercad el formato requerido (por ejemplo STL) y añádelo a esta carpeta.
