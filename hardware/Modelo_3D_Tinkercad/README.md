# Modelos 3D de VigiAire

El diseño de la carcasa y el ensamble conceptual se trabajaron en Tinkercad. El modelo en línea se puede consultar y editar desde aquí:

- [Abrir modelo VigiAire en Tinkercad](https://www.tinkercad.com/things/dmxYdAp2bKB-copy-of-vigiaire/edit)

También se incluyen en esta carpeta archivos STL de referencia del modelado de la semana 7:

- `VigiAire_S07_carcasa_preliminar.stl`: carcasa preliminar.
- `VigiAire_S07_carcasa_y_tapa_provisional.stl`: carcasa y tapa provisionales.
- `VigiAire_S07_ensamble_conceptual.stl`: ensamble conceptual.

Son modelos de referencia, no una fabricación física validada. Las dimensiones del ensamble conceptual no están verificadas; antes de imprimir o fabricar, se deben revisar medidas, ajustes entre piezas, tolerancias y configuración de laminado. El proyecto electrónico actual funciona como simulación en Wokwi; los modelos 3D representan la estructura propuesta.
